# Local Development Notes

This directory is for branch-local development records and handoff notes.

Intended usage:

- keep these notes on local branches and local remotes
- do not publish them as part of the final public patch series
- if the code is later prepared for publication, drop the documentation commit
  that adds `docs/private`

Current files:

- `qemu-fake-soc-status.md`: implementation status, decisions, validation, and
  next steps
- `qemu-fake-soc-linux-handoff.md`: environment and commands for continuing the
  work on a Linux machine
